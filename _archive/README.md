# أرشيف (_archive)

هذا المجلد يضم ملفات **قديمة ومتجاوَزة** نُقلت من جذر المستودع لتنظيمه. **لا تُستخدم للتشغيل أو الرفع.**

البرنامج الفعلي الحالي هو `TrainingSystemNet/` في جذر المستودع.

## المحتوى

- `TrainingSystem-*.zip` — لقطات ZIP قديمة لإصدارات سابقة من البرنامج (قبل وحدة الاحتياجات التدريبية TNA وتحسيناتها).
- `uploaded-part-1.zip` / `uploaded-part-2.zip` — أجزاء رفع سابقة.
- `uploaded-training-system/` — نسخة قديمة من الكود قبل إضافة وحدة TNA.
- `create_report.py` — سكربت توليد تقرير قديم.
- `تقرير-نظام-إدارة-البرامج-التدريبية.docx` — تقرير قديم (النسخة المحدَّثة صارت في `docs/`).

> كل هذه الملفات محفوظة في تاريخ Git أيضاً، ويمكن حذف المجلد بالكامل لاحقاً دون التأثير على البرنامج.
