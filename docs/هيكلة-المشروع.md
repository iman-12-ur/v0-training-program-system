## 1. نظرة عامة

المستودع يحتوي ثلاث طبقات مستقلة:

| الطبقة | المسار | الوصف | الحالة |
|---|---|---|---|
| **البرنامج الفعلي** | `TrainingSystemNet/` | تطبيق **.NET MVC** (Arabic RTL, Bootstrap 5.3.2) — هذا هو النظام الذي يُرفع ويُشغَّل | ✅ نشِط |
| معاينة v0 | جذر المستودع (`app/`, `components/`, `lib/`...) | تطبيق Next.js لأغراض المعاينة داخل v0 فقط | معاينة |
| الأرشيف | `_archive/` | ملفات ZIP قديمة ونسخ سابقة — محفوظة للرجوع فقط | مؤرشف |

> **لتشغيل/رفع البرنامج:** افتح `TrainingSystemNet/TrainingSystem.sln` في Visual Studio، أو نفّذ `dotnet run` داخل `TrainingSystemNet/TrainingSystem`.

## 3. الأدوار والصلاحيات

### الأدوار (SystemRoles)

| الدور | الوصف | النطاق |
|---|---|---|
| `SuperAdmin` | مدير النظام | كامل النظام |
| `Admin` | دائرة التدريب والتأهيل | كامل النظام |
| `DepartmentManager` | مدير الدائرة | دائرته فقط |
| `SectionHead` | رئيس القسم | قسمه فقط |
| `Supervisor` | مشرف | صلاحيات مخصّصة |

### صلاحيات وحدة الاحتياجات (TNA) — 13 صلاحية

`TrainingNeeds.View` · `Create` · `Edit` · `Submit` · `Review` · `Approve` · `Reject` · `Return` · `Manage` · `Budget` · `ImpactAssessment` · `Reports` · `Export`

> تُدار من: **الإعدادات ← المستخدمون ← إنشاء/تعديل مستخدم**، وتظهر في **مصفوفة الصلاحيات**.
> قابلة للمنح/السحب لدوري `DepartmentManager` و `SectionHead` عبر `CustomPermissions` (اتحاد مع الافتراضي).

## 4. دورة عمل الاحتياج التدريبي

```
رئيس القسم (SectionHead)
    │ ينشئ احتياجاً لموظفي قسمه
    ▼
مدير الدائرة (DepartmentManager)
    │ اعتماد | رفض | إعادة للتعديل  (لدائرته فقط)
    ▼
دائرة التدريب / مدير النظام (Admin / SuperAdmin)
    │ مراجعة نهائية → اعتماد | رفض | إعادة
    ▼
برنامج تدريبي → تنفيذ → تقييم الأثر
```

كل انتقال حالة يُسجَّل في `TrainingNeedStatusHistory` (من، إلى، بواسطة، وقت).

## 5. الأمان (عزل النطاق الإداري)

- التحقق **خادمي** عبر `User → Department → Employee`.
- `CanAccessAsync`: يمنع أي مستخدم غير مخوّل من الوصول لاحتياج خارج دائرته (حماية IDOR).
- `CanActAsManager`: يمنع الاعتماد الذاتي، ويحصر الاعتماد بدور مدير الدائرة.
- عند الإنشاء: تُشتقّ بيانات الموظف من الخادم، وتُرفض أي `EmployeeUserId` خارج دائرة المُنشئ.

## 7. كيف أُشغّل / أرفع البرنامج؟

| الغرض | الأمر / الملف |
|---|---|
| فتح المشروع | `TrainingSystemNet/TrainingSystem.sln` (Visual Studio) |
| تشغيل محلي | `cd TrainingSystemNet/TrainingSystem && dotnet run` |
| بناء | `dotnet build -c Release` |
| نشر/رفع | `dotnet publish -c Release` ثم رفع محتوى مجلد `publish/` |

> قاعدة البيانات: SQL Server عبر EF Core. سلسلة الاتصال في `appsettings.json`، والأدوار تُبذَر تلقائياً عند الإقلاع من `Program.cs`.
